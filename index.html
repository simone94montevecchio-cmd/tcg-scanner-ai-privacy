TCG Scanner AI · Informativa sul trattamento dei dati

Privacy e collegamento eBay

Ultimo aggiornamento: 17 ottobre 2026.

Stato del progetto. TCG Scanner AI è un programma Windows locale per riconoscere e revisionare scansioni di carte Pokémon. Nella versione 0.6.4 non è presente una funzione di pubblicazione tramite API eBay. Il collegamento eBay è in sviluppo e viene inizialmente configurato nell'ambiente di prova Sandbox. Questa pagina distingue il comportamento attuale dalle funzionalità previste.

1. Gestore e contatti

Il progetto è gestito dall'account GitHub simone94montevecchio-cmd. Per domande sulla presente informativa puoi utilizzare la sezione Issues del progetto. Non pubblicare password, token, indirizzi personali o dati degli acquirenti nelle segnalazioni pubbliche. Questa informativa riguarda questa distribuzione del progetto, non eventuali copie modificate da terzi.

2. Dati gestiti dal programma attuale

Il programma utilizza le scansioni selezionate dall'utente, i percorsi dei file, l'identità delle carte, la lingua, la finitura, la condizione, il prezzo, le quantità, le posizioni fisiche, le correzioni e gli esiti di riconoscimento. Sessioni, inventari e risultati vengono salvati sul computer dell'utente. Il riconoscimento delle carte viene eseguito localmente senza API OpenAI o servizi AI a pagamento.

L'aggiornamento facoltativo dei cataloghi e dei riferimenti richiede connessioni alle fonti esterne utilizzate dal programma. Il download dei riferimenti è distinto dall'invio di immagini per la vendita.

3. Collegamento eBay previsto

L'integrazione prevista consentirà all'utente di autorizzare l'app tramite OAuth sulle pagine di eBay. Il programma non dovrà richiedere né memorizzare la password eBay. I dati previsti per il collegamento comprendono credenziali dell'applicazione, token di autorizzazione e rinnovo, identificativi dell'account, regole di vendita, dati delle inserzioni, collegamenti alle immagini caricate ed esiti delle operazioni.

La prima funzione di pubblicazione è destinata alla gestione delle proprie inserzioni. Non è previsto in questa prima fase il trattamento dei dati personali degli acquirenti o la gestione degli ordini. Permessi OAuth disponibili non significano che tutte le relative informazioni siano effettivamente lette dal programma.

4. Finalità e invio a eBay

Le informazioni servono a riconoscere e controllare le carte, organizzare il magazzino e, quando la funzione sarà implementata e avviata dall'utente, caricare le fotografie e creare le inserzioni selezionate. eBay riceverà le immagini e i dati necessari alla pubblicazione, ad esempio titolo, descrizione, caratteristiche, quantità, prezzo, SKU e riferimenti alle regole di vendita. Le immagini pubblicate saranno visibili secondo il funzionamento della piattaforma eBay.

Durante le prove si utilizzano l'ambiente Sandbox e dati di test. La pubblicazione sul mercato reale richiederà un collegamento Production distinto. Si applica inoltre l'informativa privacy di eBay.

5. Conservazione e sicurezza

Nella versione attuale i dati di lavoro rimangono nei file locali, nelle esportazioni e negli eventuali backup, fino alla loro gestione da parte dell'utente. Il reset di un lotto archivia i relativi dati e non costituisce una cancellazione definitiva. L'utente deve proteggere il proprio dispositivo e le copie dei file.

Per l'integrazione eBay è prevista la conservazione locale protetta delle credenziali. Il meccanismo definitivo e i tempi di conservazione saranno documentati nella versione che implementerà il collegamento. Questa pagina non certifica che tale funzione sia già presente. Credenziali e token non devono essere inseriti nel repository pubblico, nei CSV o nei log condivisi.

6. Revoca e cancellazione

L'utente può revocare l'autorizzazione dell'app dalle impostazioni eBay. La revoca del collegamento e la cancellazione dei dati locali non eliminano automaticamente inserzioni o informazioni già inviate a eBay. Queste ultime vanno gestite sulla piattaforma. Per eliminare i dati locali occorre includere anche esportazioni e backup che si desidera rimuovere.

7. Questa pagina web

La pagina non contiene moduli, pubblicità, strumenti di analisi o script di tracciamento propri. È ospitata tramite GitHub Pages. GitHub dichiara di registrare gli indirizzi IP dei visitatori per finalità di sicurezza; si veda la GitHub Privacy Statement. L'hosting di questa pagina non comporta il caricamento su GitHub delle scansioni o dell'inventario del programma.

8. Aggiornamenti

L'informativa sarà aggiornata quando saranno definite e implementate le funzioni eBay. Prima dell'utilizzo in produzione dovrà corrispondere ai dati e alle misure effettivamente gestiti dalla versione distribuita.
